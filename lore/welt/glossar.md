# Glossar

> Quelle: `quellen/lore-komplett.md` (LK), Abschnitte LK 14. Wichtig für Kapitel: alle. Kennzeichnung der Quelle: ohne Zusatz = im Spiel belegt, **[Theorie]** = Deutung, *sinngemäß* = Inhalt, nicht Wortlaut. Für das Spiel gilt: [Theorie] nie als Tatsache erzählen. Wurzel und Lesepfade: `lore/README.md`.

| Begriff | Bedeutung |
|---|---|
| Altes Blut (Old Blood) | Das mächtige Blut aus dem Labyrinth; Grundlage der Bluttherapie, löst die Bestienseuche aus |
| Bestienseuche (Scourge of the Beast) | Die Verwandlung von Menschen in Bestien |
| Blutminister | Arzt, der Neuankömmlingen Blut verabreicht |
| Blutmond / roter Mond | Phase nach Roms Tod; Sichtbarkeit der wahren Welt |
| Bleichblut (Paleblood) | Das gesuchte Heilmittel; Schlagwort des Spiels |
| Chor | Hochrangige Forschergruppe der Kirche in der Oberen Kathedralenwache |
| Große (Great Ones) | Kosmische Wesen jenseits des Menschen; Mondgeist, Ebrietas, Mergo, Oedon, Kos u. a. |
| Kin | Zwischenwesen/Aufgestiegene; bluten klares Serum |
| Insight | Einsicht in das Unmenschliche; Statistik |
| Jägertraum | Zuflucht der Jäger, verbunden mit Gehrman und dem Mondgeist |
| Nabelschnur | Verbindung zu den Großen; Kernitem der Enden |
| Pthumerier | Uralte Zivilisation unter Yharnam |
| Schule von Mensis | Gelehrtenschule unter Micolash; Mensis-Käfig, Mensis-Ritual |
| Vilebloods | Cainhurst-Adel, Blutgemeinschaft um Königin Annalise |
| Henker (Executioners) | Orden unter Logarius gegen die Vilebloods |
